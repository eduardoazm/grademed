# GradeMed

Sistema web para cálculo e geração automatizada de grade de horários de atendimentos médicos e ambulatoriais.

## 🚀 Como Iniciar

### Desenvolvimento Local:
```bash
npm install
npm run dev
```
Acesse: [http://localhost:3000](http://localhost:3000)

### Produção / Docker:
```bash
docker compose up -d --build
```
